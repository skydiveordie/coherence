# Coherence Group — web sajt

Statički sajt (HTML + slike), bez build koraka.

## Struktura

```
index.html      Početna
kuhinja.html    Primene — Kuhinja
kupatilo.html   Primene — Kupatilo
ambijent.html   Primene — Ambijent
detalj.html     Primene — Detalj
images/         Sve fotografije, dekori i logo
```

## Objavljivanje na GitHub Pages

1. Napravite novi repozitorijum na GitHub-u.
2. Otpremite sadržaj ovog foldera u koren repozitorijuma (index.html mora biti u korenu).
3. Settings → Pages → Source: *Deploy from a branch*, grana `main`, folder `/ (root)`.
4. Sajt će biti dostupan na `https://<korisnik>.github.io/<repozitorijum>/`.

## Napomena

Linkovi `izdvajamo.html`, `secenje.html` i `projekti.html` su pripremljeni u meniju, ali te stranice još nisu napravljene.
